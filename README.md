# Atividade Prática: Animações Web e Versionamento com Git/GitHub

**Aluno:** Larissa Melo

## Descrição

Este projeto foi desenvolvido como parte da atividade prática de Animações Web e Versionamento com Git/GitHub.

O objetivo é praticar a criação de transições e animações utilizando HTML, CSS e JavaScript, além de utilizar o Git para versionamento e o GitHub para publicação do projeto.

## Animação 1 — Cartas

Na pasta `animacao` foi desenvolvida uma animação de cartas utilizando transformação 3D.

A página possui botões para:

- Virar as cartas;
- Desvirar as cartas.

Foram utilizados:

- HTML para a estrutura;
- CSS para os estilos, perspectiva 3D e transições;
- JavaScript para controlar a rotação das cartas.

## Animação 2 — Balão Subindo

Na pasta `balao` foi desenvolvida uma animação de um balão subindo pela tela.

Para realizar o movimento foi utilizado o recurso `@keyframes` do CSS, criando uma animação contínua.
